# Compatible Histories research

This research program has moved to the dedicated
[`jonland82/compatible-histories`](https://github.com/jonland82/compatible-histories)
repository.

The work began here with structural-complexity observations made during the
LeanDojo experiments, then developed into an independent program on relational
neighborhood thinning, accumulated history, Noether-defined admissibility, and
invariant measures over compatible physical histories.

The complete papers, experiments, datasets, bibliography, documentation, and
their extracted Git history are maintained in the new repository. It is
currently private and may therefore require repository access to open.

The last LeanDojo commit containing the complete in-tree research program is
`abae1937c4894b97b8c03c66a63d835b5d4f77c4`.
