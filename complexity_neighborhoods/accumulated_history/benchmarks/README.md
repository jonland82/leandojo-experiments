# Phenomenological benchmarks

These calculations calibrate scales and compare proposed rate forms with known
cosmological quantities. They are useful targets, not independent derivations.
In particular, the two-channel background is algebraically degenerate with
flat LambdaCDM until its composition law and rates are derived separately.

Run from the repository root:

```powershell
python complexity_neighborhoods/accumulated_history/benchmarks/cosmology_toy_model.py
```
