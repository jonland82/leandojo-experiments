# Causal-volume baseline

**Question:** Can raw or logarithmic total causal-past four-volume couple to
the FLRW expansion scalar with one redshift-independent coefficient?

**Objects and ensemble:** observer events along a fitted FLRW background and
their causal pasts.

**Information model:** either total four-volume or its base-two logarithm. Both
recount shared history and are proxies rather than conditional information.

**Coordinates:** covariant causal volume evaluated in an assumed flat
two-channel/LambdaCDM-degenerate background.

**Falsification criterion and result:** a constant coupling requires no drift.
Raw volume requires a 321.8-fold drift and log volume a 1.514-fold drift over
the tested range. The proxies fail; conditional causal information remains
untested.

Run from the repository root:

```powershell
python complexity_neighborhoods/accumulated_history/experiments/causal_volume/test_relativistic_history.py
```
