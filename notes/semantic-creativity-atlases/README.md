# Rarity, Compression, and Meaning in Finite Program Spaces

This directory contains the compact paper synthesizing the exact Boolean and
sorting experiments and their three validation tests.

Build from this directory with:

```powershell
latexmk -pdf note.tex
```

The paper's figures and numerical results are generated by:

```powershell
python experiments/creativity-boolean-atlas/scripts/analyze.py
python experiments/creativity-sorting-atlas/scripts/analyze.py
python experiments/creativity-atlas-validation/scripts/analyze.py
```
