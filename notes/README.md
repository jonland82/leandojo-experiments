# Research notes

Four standalone PDF notes turn the experiment sequence into compact,
paper-style reports. Each note directory contains its LaTeX source, generated
figures, build script, and checked-in PDF.

| Note | Scope | PDF |
|---|---|---|
| [`style-domain-note/`](style-domain-note/) | Tactic style versus mathematical domain | [`note.pdf`](style-domain-note/note.pdf) |
| [`semantic-embeddings-note/`](semantic-embeddings-note/) | Statement, proof, and joint semantic embeddings | [`note.pdf`](semantic-embeddings-note/note.pdf) |
| [`retrieval-generation-note/`](retrieval-generation-note/) | Retrieval-guided proof-generation pilot | [`note.pdf`](retrieval-generation-note/note.pdf) |
| [`proof-geometry-literature-note/`](proof-geometry-literature-note/) | Synthesis with related proof-geometry literature | [`note.pdf`](proof-geometry-literature-note/note.pdf) |

Build commands and prerequisites specific to each note are documented in its
`README.md`. Figure scripts should be run from the repository root so their
relative artifact paths resolve consistently.
